Why This Matters

Dictionary codes require both parties to agree on the exact reference and indexing rules. A page, column and word address is meaningful only within that shared edition. This is a practical interoperability lesson as well as a secrecy problem: a public dictionary is not a high-entropy secret key.

Historical Context

Kahn records Jefferson Davis sending Albert S. Johnston a dictionary in March 1862 and explaining the address 146.L.20 as page 146, left column, word 20, for “junction.” He also describes Confederate naval officers obtaining paired dictionaries. The evidence supports the need for matching references; it does not establish the particular Webster edition or the Lee–Johnston edition-mismatch anecdote previously associated with this example.

The matching reference and indexing rules must be shared with the intended recipient. Edition mismatch is a possible interoperability failure, not an episode established by the example above.

How It Was Broken
Dictionary Acquisition
Complexity: Easy if dictionary identified

Once the source dictionary is identified (which edition, which publisher), the code breaks completely — every page and position can be looked up directly. That is a conditional attack: this exhibit does not document a particular Union recovery of the dictionary used in the example.

⚠️

The operational failure: An edition mismatch can make a dictionary-coded message unreadable to its intended recipient. Operational cryptography must ensure that all parties can actually communicate.
