Advanced Bounded Columnar Search

Supply a known width first. The staged option estimates column adjacency, and for incomplete rectangles retains the best relative-offset alignment. Segment slides and segment swaps preserve some neighboring columns while moving larger blocks. The second phase scores the full candidate text using the museum language model.

Change one option at a time to compare searches with the same seed and budget.

Limits: widths 2–12, at most 20,000 score evaluations, including adjacency preprocessing, phase-transition scoring and every restart. Unknown-width mode divides one total budget across widths 2–12; preprocessing may exhaust a width's allocation. This bounded adaptation samples moves and combines normalized adjacency/alignment scores; it does not reproduce Lasry's alternating thresholds, exhaustive neighborhoods, optimized triplet scores or large-key performance. Language-model fitness uses the museum's bigram/trigram model. A candidate remains unverified even if it looks readable.

Source: George Lasry, A Methodology for the Cryptanalysis of Classical Ciphers with Search Metaheuristics (2018), §§5.3.2–5.3.4, printed pp. 69–78 / supplied PDF pp. 90–99. Evaluation principles: §§4.5–4.7, printed pp. 57–60 / PDF pp. 78–81.

Why This Matters

Columnar transposition was the workhorse of 19th-century military cryptography — simple enough to perform in the field without equipment, yet resistant enough to casual interception to protect battlefield communications through World War I.

Historical Context

Columnar transposition became the workhorse of 19th-century military cryptography. Simple enough to perform in the field without equipment, it resists casual interception while remaining fast to encrypt and decrypt. The system was used by various military forces throughout the 1800s and into WWI, often combined with substitution ciphers for added security.

How It Works

Write the message in rows across a grid whose width is the keyword length. Number the columns by alphabetical order of the keyword letters. Read off columns in that numbered order. Myszkowski transposition changes how repeated keyword letters are handled: tied columns are read together across each row.

Keyword: ZEBRA → Z=5, E=3, B=2, R=4, A=1
Columns:  5  3  2  4  1

How It Was Broken
Frequency Analysis + Anagramming
Complexity: Moderate

Transposition preserves the plaintext's letter counts. A distribution resembling English can suggest transposition, but does not identify it with certainty. Analysts try plausible widths and rearrange columns, looking for useful letter contacts and readable text. Several messages with the same width and column order let them test one arrangement against more evidence.

Try it: rearrange several intercepts

One promising pair of letters can be a coincidence. Can you find an order that makes three messages readable at once? Each synthetic message fills four rows of five letters. The sender read the five columns in the same secret order; we have already split each received message into five equal strips.

Select a strip and move it left or right. The corresponding column moves in every message. Read each reconstructed message across its rows. Spaces were removed; no letters were added as padding.

    What this exercise assumes

    The width, equal column lengths and shared key are supplied to isolate the rearrangement problem. Real analysis may need to establish those facts first and handle incomplete rectangles, padding or multiple transpositions. The fourth intercept deliberately uses a different column order: a key recovered for one group need not solve other traffic. “Check” compares with the known answer to these invented examples; a contact score alone cannot validate a real intercept.

    Our small contact list is: TH, HE, IN, ER, AN, RE, ON, AT, EN, ND, TI, ES, OR, TE, OF, ED, IS, IT, AL, AR, ST, TO, NT, NG, SE, HA, AS, OU, IO, LE, VE, CO, BE, RT, WA, SC, RO and UR. It is a teaching heuristic, not a fitted language model.

    Reading companions: Helen Fouché Gaines, Cryptanalysis (1939; Dover edition 1956), Chapter VII, “General Methods — Multiple Anagramming, Etc.”; Joshua Holden, The Mathematics of Secrets (2017), §3.7. These motivate the method; the messages and simplified score here were created for this exercise.

    Transposition Variants

    Classical transposition practice includes route systems, regular columnar, Myszkowski ordering, and compound forms such as double transposition. Each variant preserves letter frequencies while changing positional structure.

    The Nihilist transposition family extends these ideas into numbered-grid operations, showing how small procedural tweaks can significantly change attack difficulty.
