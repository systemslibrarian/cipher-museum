# Cipher Museum fact-check against Esslinger Chapters 1 and 3

Date checked: 2026-10-09

## Sources and method

- Bernhard Esslinger, *Learning and Experiencing Cryptography with CrypTool and SageMath* (Artech House, 2024), Chapter 1, “Ciphers and Attacks Against Them”.
- Same book, Chapter 3, “Historical Cryptology”.
- Both chapters were read from a local copy of the book. Following this repository's convention, book credit carries full title, chapter and printed page; no path to or link for an ebook copy is recorded here.
- Page numbers below are the printed page numbers, not PDF viewer indices.
- I extracted text for searching, then checked the rendered page images for Tables 1.1–1.3 and every finding where a flattened exponent could alter the result. For example, the Enigma value on p. 14 is (3.28 × 10^{114}), not `3.28 × 10114`.
- Repeated copies of the same claim in cards, timelines, tooltips, and glossary entries are consolidated into one finding and all affected locations are named.

Table 1.1 distinguishes **maximum key space** (captured base machine, replaceable parts still unknown) from **practical key space** (machine and replaceable parts captured, operational limitations known). Those are theoretical counts, not attack work factors. The site usually does not reproduce the table wholesale. Numeric site claims overlapping Table 1.1 were found for Caesar, monoalphabetic substitution, M-94, Enigma, SIGABA, Purple, Lorenz, DES, and AES-256. NEMA’s 17,576 and M-209’s 101,405,850 are explicitly called periods, not key spaces. No numeric site key-space claim was found for Hagelin C-52/CX-52, M-138A, Hebern, Kryha, Playfair, ADFGX, ADFGVX, Fialka, KL-7, VIC, or RSA-4096; their Table 1.1 values therefore are not treated as missing factual corrections.

## Book errors or internal inconsistencies noticed

- **DES date:** Chapter 1 prose says the standard was published in 1975 (p. 4), while Table 1.1 says 1976 (p. 14). The site’s 1977 corresponds to a different standardization milestone. These should not be treated as one interchangeable date.
- **M-94 date:** Table 1.1 gives 1912, while the site gives 1922. The latter matches the familiar M-94 service/designation chronology; the book entry looks like a typo or an unexplained predecessor date and needs primary-source verification.
- **Chaocipher scope:** Table 1.2’s terse PCO row appears broader than the reused-setting/in-depth conditions described by the cited 2016 work and by the site’s detailed exhibit. The cited paper, not the table shorthand, should control the final wording.
- **RSA “key space”:** Table 1.1’s (2^{4071}) for RSA-4096 is not a security-bit estimate and should not be compared to symmetric key counts as if it were an attack work factor. Chapter 1 itself warns that key-space size and work factor differ.
- **DES prose versus Table 1.3:** The early prose treats brute force as the practically effective route, while Table 1.3 lists linear cryptanalysis at (2^{43}). This is reconcilable only by accounting for the linear attack’s data requirements; quoting the exponent alone can make it look like an outright practical contradiction.
