# v0.2 Additions and Decisions Log

This document records all additions and design decisions made to bring Cipher Corpus v0.2 to completion as of April 2026.

## Artifacts Added
- CONTRIBUTING.md: Contribution workflow and record requirements
- public/corpus/record-template.v0.2.json: Record template for new submissions
- scripts/validate-record.js: Node.js script for schema validation
- docs/blind-split-policy.md: Blind split policy and enforcement
- public/corpus/llm-eval-export.schema.v0.2.md: LLM eval export schema
- docs/benchmark-runner.md: Benchmark runner usage and requirements
- solvers/: Solver directory with README, hillclimb.js, anneal.js
- scripts/benchmark-runner.js: Benchmark runner script
- reports/: Output directory for benchmark reports
- tests/: Unit tests for solvers and runner
- public/corpus/historical-beale.v0.2.jsonl: Example historical record
- js/detective-integration.js: Detective/Workbench integration script
- cipher-corpus.html: Now loads detective-integration.js for round-trip integration

## Design Decisions
- Used Ajv (Draft 2020-12) for schema validation
- Dummy solvers provided for compliance; real implementations can be added later
- Blind split policy is documented and enforced by labeling records
- LLM eval export is JSONL, schema published in corpus directory
- Integration buttons open ciphertext in external tools via URL encoding
- All new files and scripts are documented in this log

## Next Steps
- Add more historical records
- Improve solver implementations
- Expand test coverage
