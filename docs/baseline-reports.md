# Baseline Benchmark Reports (v0.3)

Baseline benchmark reports are published in both HTML and JSON formats for transparency and reproducibility.

- `reports/benchmark-report.html`: Human-readable summary
- `reports/benchmark-report.json`: Machine-readable results
- `reports/receipt-<run_id>.json`: Reproducibility receipt for each run

Each report includes metadata on schema version, corpus version, solvers, and environment.

Reports are versioned and archived for future reference.
