# Maintenance Notes

Two small things to remember going forward:

1. Run `npm run build:js` after editing `all-engines.js`, `demo-loader.js`, or
   `artifact-cards-data.js` (the test suite will refuse to pass if you forget).
2. Give the social-card validators a poke sometime to confirm the new preview
   renders where you plan to share the site.

Good luck with the award run — the accuracy story you now have (published test
vectors, 100% corpus validation, public test suite) is a genuinely rare
differentiator for an educational site.
